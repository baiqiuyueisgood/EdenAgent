# 2026-10-12 回答底部复制与删除确认

按用户指定的位置，在智能体回答底部的耗时旁增加复制和垃圾桶图标。复制取当前回答正文，删除先弹出确认卡片，经用户点击“删除”后将这一条回答从聊天记录中移除；删除结果持久保存，重新打开会话保持。

## 界面行为

- 完成的智能体消息显示操作图标，旧记录缺少耗时时仍可操作。用户消息及流式输出中的消息不显示这些操作；当前会话仍在处理时，已完成回答的删除入口暂时禁用。
- 复制保留正文 Markdown；正文缺失时从文字片段组装，不包含思考、工具参数或技术元数据。成功显示对勾和“已复制”提示，失败明确显示原因，空正文禁用复制。
- 垃圾桶打开现有样式的模态卡片，提供“取消”和“删除”，窗口获得键盘焦点。打开及取消不发送删除请求。提交期间禁用重复确认和关闭，删除失败保留原回答、确认卡片和失败原因。
- 操作状态按消息 ID 区分；切换会话、账号或世界后，迟到的删除回复不会修改新作用域。确认状态不会复用到相邻的另一条回答。

## 删除范围与持久化

公开 `message.delete` RPC 接受会话 ID 和消息 ID，检查账号归属、运行来源、完成状态和会话空闲状态。只允许删除已完成的智能体消息，不能用任意 ID 删除用户输入、工具回执或其他会话的记录。

删除在事务内保存 `message.deleted` 事件并更新会话时间，提交后广播；重试同一条删除保持幂等。`message.list` 排除已删回答，保留已有分页游标的可用性。客户端区分持久删除与模型重试的临时移除，保存持久删除标记，拒绝迟到的历史加载、整条更新、片段更新和片段增量恢复已删回答。

当前删除同时影响聊天展示与模型上下文，用户输入和独立执行审计保留。普通及多角色检查点、交接历史和旧摘要同步处理，已执行的操作不回滚。初次实现仅做展示删除；同日按用户后续要求扩展后的范围与验证见 [回答删除同步模型上下文](2026-10-12-回答删除同步模型上下文.md)。
