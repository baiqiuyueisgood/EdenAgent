# 会话右键菜单与归档

日期：2026-10-15。用户要求左侧会话列表右键出现“编辑、归档、删除”，并增加会话归档属性。

## 完成行为

- 左侧任意会话行支持右键，以及键盘菜单键或 Shift+F10。菜单包含编辑、归档、删除，操作绑定被右键点击的会话；打开菜单不切换当前会话。
- 按用户后续确认移除会话行原有的铅笔、垃圾桶悬浮按钮，并收回为按钮预留的右侧空白；相关操作统一从右键菜单进入。
- 编辑复用原有标题弹窗，删除沿用原有确认与停止/移除流程；归档等待服务端成功后才隐藏，失败时保持原会话并显示错误。菜单支持方向键、Home/End、Esc/Tab、点击外部关闭和焦点恢复，窗口边缘自动调整位置。
- 会话增加 `archived` 布尔属性，旧会话默认未归档。归档是独立的整理属性，不改变 `active/closed` 生命周期，不删除历史，不取消已有或排队任务；当前已打开会话仍可查看。
- 左侧常用列表隐藏已归档会话；“所有会话”页面显示归档标记，提供全部、未归档、已归档筛选及取消归档，恢复后可以重新出现在常用列表。关闭或删除状态不会被归档恢复操作重置。

## 后端、协议与状态归属

`packages/store` 在既有迁移末尾追加 `session_archives` 表，以会话外键持久保存归档标记；不改变原 `sessions` 六列布局，兼容原插入与历史导入。只在新宿主打开数据时自动迁移，本次测试没有打开真实用户数据库。

`packages/api` 会话摘要返回 `archived`，新增 `session.set_archived`，`session.list` 接受可选的 `archived` 筛选。未指定时保留内部/全量会话查询语义；常用列表明确请求未归档，并在 SQL 限额前筛选，避免归档条目占用前 50 条名额。

Server 写入沿用 `SessionRepository` 当前账号与世界校验，在事务中更新归档表、会话更新时间及 `session.archive_updated` 事件；幂等调用不重复发事件。事件在提交后发布，归档变更进入控制连接发现，已连接窗口和重连均能读取状态。

前端从 RPC 映射到运行态、事件 reducer、活动会话及侧栏摘要选择器，完整传递归档属性；迟到的旧列表快照或旧事件不覆盖较新的归档状态。归档请求在账号/世界切换后不向新运行态写入旧结果。虚拟列表只创建一个 Portal 菜单，目标消失或过滤后清理菜单，恢复会话时不会弹出旧菜单。
