# 源码首启提醒与主界面绘制时序

日期：2026-10-14。模块：Electron 主窗口启动、React 首帧、角色提醒及窗口重绘。

## 现象与确认范围

用户报告：刚启动源码程序时主界面白屏，提醒窗口先出现，直接第二次启动可以恢复。
源码确认 `app.whenReady()` 立即启动提醒服务，没有等待主窗口的 React 内容完成绘制。
原第二实例处理只显示、恢复并聚焦已有主窗口；如果再次运行完整开发入口，也可能重新启动开发子进程。
因此该现象指向启动或原生绘制竞态，但尚不能将提醒窗口认定为完整白屏的唯一原因。

只读历史日志包含旧 HMR Hook 错误及 Core 连接失败，没有本次白屏对应的 renderer 崩溃证据。
现有独立白屏探针仅证明干净账号下 Web 可以挂载，不能替代本次带提醒的启动顺序验证。

## 修改

- 主窗口初始关闭后台节流，避免首次绘制被隐藏或遮挡状态推迟；首次就绪后恢复正常节流。
- React 在成功挂载后的两个动画帧发出就绪 IPC；辅助页面不发送。宿主只接受主窗口主 frame 的信号。
- 宿主同时等待文档加载、原生 `ready-to-show` 和 React 首帧后再启动提醒服务，导航清除旧信号，关闭或完成后移除监听。
- 初次启动完成后，提醒继续独立运行；主窗口隐藏或关闭到托盘不会再次阻塞提醒。账号切换及两个世界的已有队列规则保留。
- 提醒使用按世界划分的非持久 Electron session，不与主界面共享默认浏览器会话。提醒 renderer 崩溃后销毁该窗口，由已有有界重试读取未关闭的持久提醒；不伪造关闭回执。
- 主窗口重新获得焦点时合并请求完整表面重绘，补齐第二次启动、提醒关闭后返回主界面的重绘路径。

以上是浏览器会话及进程生命周期处理，不恢复 OS 执行沙箱，不修改 Agent 数据库或业务调度。

## 实际验证

Windows 系统 Node 24.21.0、项目 Electron 42.4.0；只使用临时目录、干净浏览器 profile、合成提醒及模拟 RPC，不使用用户账号或数据库作为夹具。

1. `node --test frontend/desktop/tests/primary-renderer-startup.test.cjs frontend/desktop/tests/window-repaint.test.cjs frontend/desktop/tests/reminder-service.test.cjs frontend/desktop/tests/reminder-layout.test.cjs frontend/desktop/tests/reminder-startup-renderer.test.cjs`：18/18 通过，无跳过。
   - 实际 React、sandbox preload 和 IPC 验证旧启动调度能在主窗口 root 为空时打开提醒；新调度在主窗口绘制之前不查询或创建提醒。
   - 使用真实隐藏 Electron 窗口加载提醒 HTML，验证其 renderer 与主窗口不同。人为仅使夹具提醒 renderer 崩溃后，提醒重新读取，主窗口 DOM 保持完整；实际按钮通过 preload/IPC 关闭提醒后主窗口内容仍完整。
   - 所有测试原生窗口保持隐藏，没有操作用户桌面窗口。旧顺序对照复用了当前提醒窗口实现，仅用于确认启动时序，不能据此推断旧浏览器会话的崩溃传播行为。
2. `node --test frontend/desktop/tests/realm-rpc.test.cjs frontend/desktop/tests/renderer-console-message.test.cjs frontend/desktop/tests/web-app-loader.test.cjs frontend/desktop/tests/console-encoding.test.cjs`：19/19 通过，无跳过。
3. `npm --prefix frontend/web run typecheck`、`npm --prefix frontend/web run build`：通过，主题检查覆盖 297 个文件；构建保留原有大 chunk 提醒。
4. 三个改动 CJS 入口 `node --check` 通过；`node Script/Architecture/check.mjs` 为 1115 个文件、0 错误，保留已有规模警告，门禁范围仍不包含 frontend。
5. 隔离真实 Web 开发入口及当前 preload 验证：root 非空、运行方式选择页面正常、没有 console error 或主 frame 加载失败、首次就绪后后台节流恢复为 true。
   初次诊断探针在截图完成后于 Electron 退出阶段同步清理 profile 时未退出；只终止该隔离探针，移除进程内清理后复跑退出码 0。没有关闭在线开发桌面或 Server。

## 交付边界

源码及本地 Web 构建已更新，未修改安装包、正式版本、提交或推送，也没有替换或重启在线服务。
Electron 主进程和 preload 需要完整退出后重新 `npm run dev` 才会加载；仅 Vite 热更新不能更新这些部分。
已复现并修正提醒先于主界面绘制的启动缺口，没有复现用户机器上完整的原生白屏或证明唯一根因。
用户真实账号、可见桌面冷启动、睡眠恢复及 GPU/显示驱动条件仍需在正常新版首启中确认。
